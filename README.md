# Nyll_OS
A web OS 
Project Status: Ongoing
<br>
Nyll_OS is a WebOS created fully by me. You can write notes, use a calculator, browse, and more!
<br>
How is this project being tracked?
<br>
This project is being tracked by Hackatime, which counts every second I'm actually programming. On top of that, I'll be documenting <br>
every step in the Journal that's in this repo.
